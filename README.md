# Mie Academy — Program Blueprint

Client-facing blueprint for **Mie Academy**, a hybrid Grades 9–12 homeschool academy built on the *Unapologetic — Redefine Standards* literacy framework.

- **Academy vision and progression**: pillars (Group Economics, Practical Problem-Solving, Hybrid Learning), a Grade 9–12 selector with sample weeks, literacy lens, economics focus and capstones.
- **Technology and IT infrastructure**: the enrollment tech kit manifest and the MDM / identity / LMS / safety / governance stack.

Single self-contained `index.html` (React 18 + Tailwind via CDN). Open it in a browser, or serve it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Template framework — client preview. Prepared for consultation by Stealth Tech Services.
